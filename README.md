# Anbu v1 — R4N

Analog colour stage / opto compressor for vocals (VST3, Windows 64-bit).
LA-2A-style Peak Reduction with program-dependent tone and distortion, Lindell-80-style Color (overkill at the top),
inherent depth, and a hardware panel.

## Get the plugin
1. **Actions** tab → latest green run of *Build Anbu (Windows VST3)* → **Artifacts** → **Anbu-VST3-Windows**.
2. Unzip, then copy **`Anbu.vst3`** to `C:\Program Files\Common Files\VST3`.
3. FL Studio → **Options → Manage plugins → Find installed plugins**.

Every push to this repo builds a new version automatically. More detail: [INSTALL.md](INSTALL.md).
